# Algorithm Documentation

## 1. find_page_bounds — كشف حدود الصفحة

### الوصف
يكتشف حدود الصفحة باستخدام تحليل Median فقط، وهو أكثر موثوقية مع النصوص الكثيفة مقارنة بالمتوسط (Mean).

### المدخلات
- `img`: صورة NumPy (BGR أو Grayscale)
- `page_threshold`: عتبة السطوع (افتراضي: 200)
- `min_page_fraction`: الحد الأدنى لنسبة الصفحة (افتراضي: 0.25)

### المخرجات
- `(left, top, right, bottom)`: حدود الهوامش بالبكسل

### الخوارزمية
```
1. تحويل إلى تدرج رمادي إذا لزم
2. حساب Median لكل عمود (col_med)
3. البحث عن حدود أفقية:
   - صفوف حيث Median > threshold
   - أصغر منطقة مستمرة > min_fraction * width
4. حساب Median لكل صف داخل المنطقة الأفقية المكتشفة
5. البحث عن حدود عمودية بنفس الطريقة
6. إضافة هامش 5px
```

### تعقيد الوقت
O(W*H) — حيث W و H هما أبعاد الصورة

## 2. auto_detect_skew — كشف الميلان

### الوصف
يكتشف زاوية ميلان الصفحة باستخدام تحسين تباين الإسقاط الأفقي مع تحقق من أن التحسن >5% فوق 0°.

### المدخلات
- `img`: صورة NumPy
- `max_a`: أقصى زاوية بحث (افتراضي: ±5°)
- `step`: خطوة البحث (افتراضي: 0.25°)

### المخرجات
- `float`: زاوية الميلان (0.0 = مستقيم)

### الخوارزمية
```
1. إزالة الحدود الرمادية عبر find_page_bounds()
2. تحضير الصورة:
   - Gaussian Blur (3×3)
   - CLAHE contrast enhancement
   - Otsu binary threshold
3. لكل زاوية في [-max_a, +max_a]:
   - تدوير الصورة الثنائية
   - حساب sum(axis=1) → الإسقاط الأفقي
   - score = variance * (1 + non_empty_ratio)
4. حساب score للزاوية 0°
5. التحقق: إذا best_score < score_0 * 1.05 → إرجاع 0.0
6. إذا abs(angle) < 0.3 → إرجاع 0.0
```

### ملاحظات
- نطاق ±5° بدلاً من ±15° لتقليل الوقت
- التحقق من 5% يمنع الكشف الخاطئ للصفحات المستقيمة
- CLAHE يحسن التباين في المناطق المظلمة

## 3. smart_auto_crop — القص الذكي

### الوصف
قص ذكي من مرحلتين: إزالة الحدود الرمادية ثم كشف محتوى الصفحة.

### المدخلات
- `img`: صورة NumPy
- `padding`: حشوة إضافية (افتراضي: 15px)
- `dark_threshold`: عتبة المحتوى (افتراضي: 200)

### المخرجات
- `(left, top, right, bottom)`: هوامش القص

### الخوارزمية
```
المرحلة 1: إزالة الحدود
  - find_page_bounds(img) → حدود الصفحة
  - استخراج منطقة الصفحة

المرحلة 2: كشف المحتوى
  - تحويل إلى تدرج رمادي
  - Binary threshold عند dark_threshold
  - البحث عن أول/آخر صف/عمود به محتوى
  - إضافة padding
```

## 4. segmentPage — تقسيم الصفحة إلى كلمات

### الوصف
يقسم صورة صفحة مكتوبة بخط اليد إلى كلمات فردية عبر كشف الأسطر ثم تقسيم كل سطر.

### المدخلات
- `imageBuffer`: Buffer الصورة (PNG/JPEG)

### المخرجات
- `WordSegment[]`: مصفوفة الكلمات المكتشفة

### الخوارزمية
```
1. preprocessing:
   - تحويل إلى رمادي
   - Histogram equalization (CLAHE-like)
   - Otsu threshold → binary
   - Mild sharpening

2. findLines (horizontal projection):
   - حساب sum(axis=1) لكل صف
   - كشف مناطق النص حيث projection > 5% of max
   - الحد الأدنى للفجوة: 5px
   - تصفية الأسطر القصيرة (< 0.5% من الارتفاع)

3. segmentWordsFromLine (vertical projection):
   - حساب sum(axis=0) لكل عمود داخل السطر
   - كشف الكلمات حيث projection > 3% of max
   - الحد الأدنى للفجوة: 2px
   - إضافة padding 3px

4. Crop words from original image using Sharp
```

## 5. calc_blur — حساب درجة الوضوح

### الوصف
يحسب درجة ضبابية الصورة باستخدام تباين لابلاسيان.

### المدخلات
- `img`: صورة NumPy أو Buffer

### المخرجات
- `float`: درجة الوضوح (أعلى = أوضح)

### الخوارزمية
```
1. تحويل إلى رمادي
2. حساب Laplacian (cv2.CV_64F)
3. إرجاع variance(values)
```

### تفسير القيم
- < 100: ضبابية جداً
- 100-500: مقبولة
- > 500: واضحة
- > 1000: ممتازة

## 6. KNN Prediction — التنبؤ بالإعدادات المثالية

### الوصف
يتنبأ بالإعدادات المثالية لمعالجة صورة جديدة باستخدام K-Nearest Neighbors.

### المدخلات
- `img`: صورة NumPy
- `K`: عدد الجيران (3)

### المخرجات
- `predicted_params`: الإعدادات المتوقعة
- `confidence`: درجة الثقة (0-1)

### الخوارزمية
```
1. استخراج 30 ميزة من الصورة الجديدة
2. حساب التشابه مع جميع سجلات التدريب
   - تشابه مرجح: aspect_ratio, brightness, blur, edges, etc.
   - تشابه الرسم البياني: 16-bin histogram
3. اختيار أعلى K=3 جيران
4. إذا أفضل تشابه < 0.80 → لا اقتراح
5. حساب المتوسط المرجح للإعدادات:
   - crop: weighted average
   - deskew_angle: weighted average
   - flip_h: majority vote (>0.5)
   - sharpen: majority vote (>0.5)
   - rotation: highest weighted vote
```

## 7. ImageFeatureExtractor — استخراج الميزات

### الميزات المستخرجة (30 ميزة)

| الميزة | الوصف | النطاق |
|--------|-------|--------|
| w, h | الأبعاد | pixels |
| aspect_ratio | نسبة العرض/الارتفاع | 0-∞ |
| brightness_mean | متوسط السطوع | 0-255 |
| brightness_std | انحراف السطوع | 0-128 |
| blur_score | تباين لابلاسيان | 0-∞ |
| edge_density | كثافة الحواف | 0-1 |
| horiz_proj_var | تباين الإسقاط الأفقي | 0-∞ |
| vert_proj_var | تباين الإسقاط العمودي | 0-∞ |
| dark_ratio | نسبة البكسلات المظلمة | 0-1 |
| grad_mean | متوسط التدرج | 0-∞ |
| hist_00 - hist_15 | الرسم البياني (16-bin) | 0-1 |
