# training-data/patterns

أرشيف `oms.pattern.v1`: سطر JSON لكل قصاصة حرف أو كلمة.

- `text` هو النص الصحيح الذي أكّده المراجع، لا تخمين المحرك.
- `review: confirmed` وحده يُصدَّر للتدريب. `open` و`rejected` مستبعدان من JSONL المُصدَّر.
- غياب `review` يعني `open`؛ لا ترقية تلقائية للسجلات القديمة.
- `image_png_base64` قصاصة الصفحة لا الصفحة كاملة.
- `/api/pattern-studio/dataset/export` يُرجع JSONL ولا يكتب الملف إلى المستودع تلقائياً؛ يُراجع الناتج ويُلتزم على فرع.
- لا تُودع هنا صوراً تخص مرضى.

الإضافة تتم بتصدير الاستوديو ثم التزام الملف على فرع، لا بالكتابة المباشرة على `main`.
