# 📤 Telegram Channel Copier

نسخ جميع الملفات والرسائل من قناة عامة إلى قناتك الخاصة عبر واجهة ويب سهلة.

## 🚀 الاستخدام

1. افتح الـ Space على Hugging Face
2. أدخل بيانات API الخاصة بك
3. حدد القناة المصدر والهدف
4. اضغط "بدء النسخ"

## ⚙️ الإعدادات

| الخيار | الوصف |
|--------|-------|
| API ID | من my.telegram.org |
| API Hash | من my.telegram.org |
| القناة المصدر | معرف القناة العامة (مثال: @channel) |
| القناة الهدف | المعرف الرقمي للقناة الخاصة |
| التأخير | الانتظار بين كل رسالة (ثواني) |
| عدد الرسائل | 0 = الكل، أو عدد محدد |

## ⚠️ تحذيرات

- تأكد من صلاحية النشر في القناة الهدف
- زيادة التأخير للقنوات الكبيرة لتجنب الحظر
- لا تشارك بيانات API مع أحد

## 🔒 الأمان

يتم حفظ جلسة تليجرام في ملف `session.session` داخل الـ Space. لا تشارك هذا الملف.
