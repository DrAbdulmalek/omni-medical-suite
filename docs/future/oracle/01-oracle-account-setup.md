# 01 — Oracle Account Setup (V-0 · PLANNED)

## خطوات التسجيل
1. https://signup.oraclecloud.com → **Start for free**.
2. بريد + تحقق + كلمة قوية (مدير كلمات مرور).
3. **Home Region**: اختر الأقرب/الأوفر سعة (مثل Frankfurt/Amsterdam) — **لا تُغيَّر لاحقًا** وتحدد أين تُنشأ موارد Always Free.
4. بيانات الهوية: اسم/عنوان/هاتف — **دقيقة وقابلة للإثبات** (سبب شائع للرفض: تعارض العنوان مع البطاقة).
5. بطاقة دفع للتحقق (خصم مؤقت صغير يُرد) — راجع خيارات سوريا في [../vps/FREE_VPS_OPTIONS.md](../vps/FREE_VPS_OPTIONS.md).
6. اختيار "Individual" (لا شركة إلا بوثائق).
7. انتظار الموافقة (دقائق→أيام)؛ قد تطلب Oracle تحققًا إضافيًا.

## مشاكل التسجيل الشائعة (وحلولها)
| المشكلة | الحل |
|---|---|
| رفض البطاقة | بطاقة أخرى/prepaid مقبولة؛ تأكد تطابق العنوان؛ أعد بعد 24-72h |
| "Unable to verify information" | بيانات متسقة حرفيًا (الاسم كما في البطاقة)؛ متصفح/جهاز آخر |
| Home Region ممتلئ (Ampere) | جرّب وقتًا مبكرًا (UTC صباحًا)؛ أو ابدأ بـAMD micro ثم اطلب ARM عند التوفر ("Out of capacity" شائع — UNVERIFIED) |
| طلب تحقق هاتفي لا يصل | رقم بصيغة دولية صحيحة؛ بديل اتصال |
| تعليق حساب لاحق | افتح ticket فورًا؛ لذلك **لا مصدر وحيد للبيانات على Oracle** (R3) |
