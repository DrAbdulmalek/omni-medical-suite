# FAQ — أسئلة شائعة (PLANNED)

**1) هل VPS آمن لبيانات المرضى؟**
لا تضع PHI غير مشفر على VPS عام أبدًا. المسموح: اصطناعي/مشفّر فقط — التفاصيل والاضطرارات في [PRIVACY_COMPLIANCE.md](PRIVACY_COMPLIANCE.md).

**2) ماذا لو فقدت الـVPS؟**
لا شيء يُفقد إن اكتملت V-4: نسخ يومية مشفرة في GitHub private + B2؛ الاستعادة = VM جديد + runbook (03→08) + فك تشفير آخر نسخة. اختبار الاستعادة شهري إلزامي.

**3) كيف أنقل البيانات من جهازي؟**
عبر قناة مشفرة فقط: tar → GPG → رفع (gh/scp) → تحقق SHA256 → فك على VPS. لا بريد/لا خدمات تحويل ملفات عامة.

**4) كم التكلفة السنوية الفعلية؟**
$0 في المسار المجاني الكامل (Oracle+Colab+GitHub). ~$170-230/سنة في المختلط (Colab Pro + GitHub Pro). انظر [COST_ANALYSIS.md](COST_ANALYSIS.md).

**5) هل أحتاج خبرة Linux؟**
أساسيات: ssh، systemctl، nginx config، cron. كل خطوة موثقة في oracle/00-11 بقوالب idempotent — المستوى المطلوب "متوسط مبتدئ مع متابعة دقيقة".

**6) ماذا لو رُفض طلب Oracle؟**
متوقع (احتمال عالٍ — R3): أعد المحاولة بعد أيام ببيانات أدق/بطاقة أخرى مقبولة، وفعّل الخطة البديلة Codespaces+Colab فورًا ([ALTERNATIVES.md](ALTERNATIVES.md)).

**7) هل VPS أسرع من جهازي؟**
للخدمات الدائمة نعم (24/7 + اتصال مستقر)، وللتدريب **لا** (بلا GPU — التدريب يبقى Colab). ARM Ampere 4c/24GB يتفوق على أجهزة laptops متوسطة في التقطيع/الاستدلال CPU.

**8) كيف أستعيد العمل بعد إعادة تعيين البيئة (reset)؟**
نفس بروتوكول ATR: PROGRESS.md + GitHub هو مصدر الحقيقة + handoff bundles. هذه الحزمة نفسها وُجدت لهذا السبب — كل شيء مدفوع على فرع بعيد.

**9) هل أستطيع تشغيل التدريب على VPS؟**
لا عمليًا (بلا GPU؛ وRAM محدود أمام torch+TrOCR). VPS = تصحيح/تقطيع/استدلال خفيف فقط؛ التدريب Colab (V-6).

**10) ماذا عن الكهرباء/الإنترنت عندي؟**
المعمارية الهجينة مصممة لذلك: VPS يخدم 24/7 unabhängig؛ جهازك يتصل متى توفر؛ Colab يُشغَّل من المتصفح أو بجداول GitHub Actions.

**11) هل أحتاج نطاقًا (domain)؟**
اختياري. IP + Let's Encrypt يعمل (شهادة على IP ممكنة بشروط) أو نطاق رخيص (~$10/سنة) — الأنظف لن nginx/SSL.

**12) متى أعتبر المنظومة "إنتاجًا"؟**
عند اكتمال V-7 (استقرار أسبوعين) — وأي ادعاء "medical HTR production" يبقى ممنوعًا حتى اجتياز بوابة التحقق على corpus حقيقي معتمد (قرار PR #136).
