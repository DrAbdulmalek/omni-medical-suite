## 3. الاكتشاف الوحيد الذي يجب التصرف فيه الآن

من كل ما جاء في تقرير Grok، **هذه النقطة تهمّ:**

| Provider | Local/External | Default enabled? | Privacy gate? |
|----------|----------------|------------------|---------------|
| Mixed | Local | ✅ | ❌ |
| Tesseract | Local | ✅ | ❌ |
| **Mistral** | **External** | **✅ (ثالثًا!)** | **❌** |
| EasyOCR | Local | ✅ | ❌ |

**المعنى بلغة صريحة**: مشروع طبي، في وضع Offline-First، يرسل صور المستندات إلى Mistral Cloud إذا فشلت المحركات المحلية — **بلا أي بوابة خصوصية، بلا إشعار، بلا علم المستخدم**.

هذا **خرق حقيقي**. في مشروع طبي، هذا قد يعني:
- صورة روشتة مريض → Mistral Cloud
- نص تقرير طبي → Mistral Cloud
- في بلد فيه قوانين PHI/HIPAA → مخالفة قانونية

**الإصلاح**: سطر واحد في `packages/omni_ocr/adapter.py`:

```python
# قبل:
_DEFAULT_ENGINE_ORDER = [MIXED_ENGINE, TESSERACT, MISTRAL, EASYOCR]

# بعد:
_DEFAULT_ENGINE_ORDER = [MIXED_ENGINE, TESSERACT, EASYOCR]
# Mistral يُضاف فقط إذا فعّله المستخدم صراحةً
if os.getenv("OMNI_ENABLE_CLOUD_OCR") == "1":
    _DEFAULT_ENGINE_ORDER.append(MISTRAL)
```

**هذا هو أهم ما في التقرير كله.** كل شيء آخر ثانوي.
