## 1. Bug Fixes & Hardening

### 1.1 CI Smoke Stabilization
- **Problem**: `mobile-smoke` job in `rc-gate.yml` may fail if `packages.core.mobile.server` path resolution differs between local and CI environments.
- **Fix**: Add explicit `PYTHONPATH=$(pwd)` and `sys.path.insert(0, os.getcwd())` in server entry point. Add retry logic with 10-second timeout for health check.
- **Priority**: P0 — blocks release gate

### 1.2 systemd --user on Manjaro
- **Problem**: Installer falls back to manual launch in containers; full systemd lifecycle untested on native Manjaro.
- **Fix**: Add Manjaro-specific CI job (or self-hosted runner) that validates: `systemctl --user start omni-medical-pwa` → `/health` → `systemctl --user stop`.
- **Priority**: P1 — important for desktop users

### 1.3 AppImage Wayland Fallback
- **Problem**: AppImage may fail on KDE Plasma 6 Wayland without `QT_QPA_PLATFORM=wayland;xcb`.
- **Fix**: Update `AppRun` to detect Wayland session and set platform with xcb fallback automatically. Add `QT_QPA_PLATFORMTHEME=kdedefaults` for consistent theming.
- **Priority**: P1

### 1.4 LFS Pointer Integrity
- **Problem**: Files that were committed before LFS tracking may show "should have been a pointer" warnings on checkout.
- **Fix**: Run `git lfs checkout` in post-clone instructions. Add to `install_mobile_pwa.sh` as a step. Verify all 33 LFS-tracked files are valid pointers.
- **Priority**: P1

## 2. Desktop GUI Completion

### 2.1 Full Desktop Integration
- **Problem**: Desktop GUI (`packages/desktop/medical_doc_gui_final.py`) is partially integrated — PySide6 app builds but lacks proper window management and settings persistence.
- **Fix**: 
  - Add QSettings-based configuration persistence (last directory, theme, language)
  - Wire up scanner_fixer pipeline as a background thread with progress bar
  - Add drag-and-drop file import
  - Proper About dialog with version + build info
- **Priority**: P1 — key user-facing feature

### 2.2 System Tray Integration
- **Problem**: AppImage exits when window is closed; no way to keep running in background.
- **Fix**: Add QSystemTrayIcon with minimize-to-tray, quick-capture, and status indicator.
- **Priority**: P2

## 3. CI/CD Improvements

### 3.1 HF Space Drift Gate
- **Problem**: `deploy-to-hf.yml` pushes whenever `hf-space/` changes, but there's no drift detection to prevent stale deployments.
- **Fix**: Add `check_hf_space_drift.py` as a pre-deploy gate in the workflow. If drift > threshold, fail and require manual sync.
- **Priority**: P1

### 3.2 AppImage Build Caching
- **Problem**: AppImage builds take 30-45 minutes due to full PyInstaller rebuild each time.
- **Fix**: Cache `packages/desktop/dist/` and `packages/desktop/build/` between runs using `actions/cache`. Only rebuild when source files change.
- **Priority**: P2

### 3.3 Release Automation
- **Problem**: Tag push triggers `release.yml` but AppImage artifact may not be ready for hours.
- **Fix**: Add Slack/Discord webhook notification on release completion. Upload release artifact checksum to a known location for verification.
- **Priority**: P2

## 4. Security

### 4.1 Token Rotation Procedure
- **Problem**: GitHub PAT was exposed in a previous session. Must be revoked and replaced.
- **Fix**: 
  1. Revoke at https://github.com/settings/tokens
  2. Create new PAT with minimal scopes (`repo`, `workflow`)
  3. Update `secrets.GITHUB_TOKEN` and `secrets.HF_TOKEN` in repo settings
  4. Add `credential-scan.yml` to catch future leaks pre-push
- **Priority**: P0 — immediate action required

### 4.2 Pre-push Secret Scanning
- **Problem**: GitHub push protection caught the token but only on push, not locally.
- **Fix**: Add `pre-commit` hook with `detect-secrets` or `gitleaks` to scan before commit.
- **Priority**: P1
