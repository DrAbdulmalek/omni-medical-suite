# Telegram OCR Studio — استوديو التعرف الضوئي لتيليجرام

واجهة Gradio عربية (RTL) ضمن `omni-medical-suite` تجمع أربعة عناصر في دورة
واحدة مستوحاة من ABBYY FineReader:

```
قناة تيليجرام ──▶ صندوق الاستلام ──▶ OCR محلي (ara+eng)
                                        │
                                        ▼
        قاعدة بيانات GitHub ◀── أنماط متعلمة (字模) ◀── قصاصات معلّقة
```

## التبويبات
| التبويب | الوظيفة |
|---|---|
| 📡 القناة | فحص جلسة Telethon، عرض الملفات القابلة للتعرف (صور/PDF)، تنزيلها |
| 🔍 التعرف الضوئي | Tesseract محلي + معالجة مسبقة + تحسين بالأنماط المتعلمة |
| ✂️ القصاصات | اقتطاع حرف/كلمة/سطر + تعليق نصي صحيح (HITL) |
| 🧠 الأنماط | مكتبة قوالب 96×48 تُبنى من القصاصات وتُستخدم في المطابقة |
| 🗄️ قاعدة بيانات GitHub | إحصاءات + تصدير حزمة تدريب + مزامنة إلى المستودع الخاص |

## التشغيل
```bash
cd repos/omni-medical-suite
python apps/telegram-ocr/app.py            # المنفذ 7861
# بيانات الاتصال: env TELEGRAM_* أو مجلد الأسرار المُعد مسبقاً
# التوكن للمزامنة: env GH_TOKEN أو ~/.zai-gh-token
```

## المتطلبات
`tesseract-ocr` (مع `ara+eng` في `OMNI_TESSDATA_PREFIX`)، `pymupdf`،
`telethon`، `gradio>=5`، `opencv-python`، `pytesseract`.
